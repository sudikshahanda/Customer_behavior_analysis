# 📊 Customer Shopping Behavior Data Analysis

## Overview

This project focuses on analyzing customer shopping behavior using Python, SQL, and Power BI. The objective is to transform raw data into meaningful business insights through data cleaning, exploratory data analysis (EDA), SQL-based querying, and interactive dashboard creation.

The project demonstrates an end-to-end data analytics workflow, from data collection to reporting and visualization.

---

## Dataset

The dataset contains customer shopping information, including:

* Customer demographics
* Product categories
* Purchase details
* Spending patterns
* Shopping frequency
* Payment methods

**Source:** Customer Shopping Behavior Dataset

## Project Workflow

### 1. Data Loading

* Imported dataset using Python.
* Performed initial inspection of rows, columns, and data types.

### 2. Exploratory Data Analysis (EDA)

* Analyzed data distribution and trends.
* Identified customer purchasing patterns.
* Created visualizations to understand key metrics.

### 3. Data Cleaning

* Handled missing values.
* Removed duplicate records.
* Corrected inconsistent data formats.
* Prepared data for analysis and reporting.

### 4. SQL Analysis

* Loaded cleaned data into PostgreSQL/MySQL/SQL Server.
* Executed SQL queries to:

  * Calculate sales metrics
  * Identify top-performing categories
  * Analyze customer behavior
  * Generate business insights

### 5. Dashboard Development

* Built an interactive Power BI dashboard.
* Added KPIs, charts, filters, and slicers.
* Enabled dynamic data exploration.

### 6. Reporting & Presentation

* Documented findings in a business report.
* Created a presentation using Gamma AI.
* Summarized insights and recommendations.

## How to Run

### Step 1: Clone the Repository

```bash
git clone https://github.com/your-username/data-analytics-project.git
cd data-analytics-project
```

### Step 2: Install Dependencies

```bash
pip install pandas numpy matplotlib seaborn
```

### Step 3: Run the Analysis

```bash
jupyter notebook
```

Open the notebook and execute all cells.

### Step 4: Run SQL Queries

* Import the cleaned dataset into PostgreSQL/MySQL/SQL Server.
* Execute queries from the `sql/analysis_queries.sql` file.

### Step 5: Open Power BI Dashboard

* Launch Power BI Desktop.
* Open the `.pbix` file.
* Refresh data connections if required.
